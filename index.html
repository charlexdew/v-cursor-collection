Installation

  1. Choose a color and finish, then download its archive.
  2. Open System Settings → Colors & Themes → Cursors.
  3. Choose Install from File and select the .tar.gz.
  4. Select the installed theme and apply. Restart apps that cache old cursors.

SVG cursors require Plasma 6.2 or later. Tested with KWin 6.8.2 on Wayland. Downloading a theme does not install or activate it.

Compatibility and limitations

Some animations play once and stop on the final image. They use a zero-delay final frame, which works in the tested KWin version but does not follow KDE’s animation specification. Future KWin versions may behave differently.

XCursor versions use static images for those transitions. Link, wait and progress still animate. Other desktops and apps may behave differently. Glass uses transparency, not background blur.

Preview animation is off by default and respects your reduced-motion setting.
